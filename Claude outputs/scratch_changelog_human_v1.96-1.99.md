DiscForge — What's New (v1.96.0 through v1.99.0)
==================================================

This covers everything added since the last update: DVDFab, ten more external tools you can
launch straight from the app, and three brand new screens for jobs DiscForge didn't have a home
for before.

DVDFab added to the Read screen
--------------------------------
DVDFab now sits alongside Xreveal and CloneBD on the disc-reading screen. It's the all-in-one
version of what those two already do separately — ripping protected DVDs and Blu-rays — so it's
offered as an extra option, not a replacement for either.

Four new tools for Xbox, Wii and PS1
-------------------------------------
- **Xbox Backup Creator** and **abgx360** — both now available from the Xbox screen. Xbox Backup
  Creator handles the disc-reading step DiscForge itself can't do for Xbox and Xbox 360 games;
  abgx360 checks and repairs the resulting file afterward.
- **Wiimms ISO Tools** — now available from the disc-reading screen, next to the existing
  GameCube/Wii button. Use it right after dumping a Wii disc to turn the raw dump into a clean,
  usable ISO.
- **MemcardRex** — now available from the Memory Cards screen. DiscForge can read and pull saves
  off a PlayStation memory card, but MemcardRex is what you'd use to edit a save or put one back
  onto a card.

Two more save-editing tools, and a new Floppy screen
------------------------------------------------------
- **PS2 Save Builder** and **GCMM** — both now on the Memory Cards screen next to MemcardRex.
  Same idea, for PlayStation 2 and GameCube saves: DiscForge reads them, these tools let you edit
  or write them back.
- **A new Floppy screen** — with buttons for **KryoFlux** and **Greaseweazle**, the two most
  common pieces of hardware for capturing old floppy disks at a very low level. DiscForge can
  already read the files these tools produce; this just gives you a quick way to launch the
  capture software itself.

Two more new screens: PSP and Cartridges
-------------------------------------------
- **A new PSP screen** — with a button for **UMDGen**, a tool for opening and editing PSP game
  images. Worth knowing: this one's for editing a PSP image you already have, not for copying a
  UMD disc — that step still has to happen on a modified PSP itself.
- **A new Cartridges screen** — with buttons for **GBxCart RW / FlashGBX** and **Cart Reader**,
  two popular pieces of hardware for dumping game cartridges. GBxCart RW covers Game Boy, Game
  Boy Color and Game Boy Advance; Cart Reader covers N64, SNES, Genesis and NES. There isn't one
  single standard tool for cartridge dumping the way there is for discs, so both are offered.

How all of these work
-----------------------
Every button above works the same way: the first time you click it, DiscForge asks you to point
it at the program on your computer, then remembers that choice so you're not asked again. None of
these tools are included with DiscForge or installed by it — you'll need to already have (or go
get) whichever ones you plan to use.

What hasn't been tested yet
-----------------------------
All of this has been checked as carefully as possible without actually running the finished app,
but every one of these screens and buttons still needs a real look on a Windows machine to
confirm the buttons are laid out cleanly and everything launches as expected.
